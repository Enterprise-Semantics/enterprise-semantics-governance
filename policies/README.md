# Policies

This directory holds governance-level policies. Per CR-ES-001 §10.

## When to use

Use this directory for:

- Cardinal rules that apply org-wide (e.g. Author field rule, vendor-specific embargo).
- Operational policies (e.g. plan-keeper cron behaviour, drift alarm thresholds).
- Security policies (e.g. credential handling, PAT scope rules).

## Naming convention

`NNNN-policy-<short-title>.md` where NNNN is the next available slot.

## Status

Empty at v0.0.1. Cardinal rules are stated in `plans/PLAN-CHANGELOG.md` and MEMORY.md, migration to this directory as standalone policy documents is held for a future housekeeping CR.
