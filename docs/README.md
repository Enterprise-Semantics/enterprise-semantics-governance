# Governance Documentation

This directory holds governance-level narrative documentation. Per CR-ES-001 §10.

## When to use

Use this directory for:

- Long-form governance narratives (e.g. the lifecycle, the decision hierarchy).
- Cross-ADR summaries (e.g. "all architectural decisions to date").
- Operational runbooks (e.g. how to author an ADR, how to file a CR).

## Naming convention

`NNNN-short-title.md` where NNNN is the next available slot.

## Initial content

`001-lifecycle.md`, the governed lifecycle from Finding to Release, with operational guidance for each artefact type.
