# Templates

This directory holds governance templates beyond the `0000-template.md` series. Per CR-ES-001 §10.

## When to use

Use this directory for templates that:

- Are not the canonical ADR/CR/Finding template (those live at `../docs/adr/0000-template.md`, `../docs/cr/0000-template.md`, `../docs/finding/0000-template.md`).
- Apply to a specific artefact type (e.g. profile template, schema template).
- Are reused across multiple governance artefacts.

## Naming convention

`NNNN-template-for-<artefact>.md` where NNNN is the next available slot.

## Status

Empty at v0.0.1 ;;; first templates will be introduced as concept-specific CRs require them.
